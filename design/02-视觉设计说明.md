# 视觉设计说明 · 和尚鹦鹉套装报价单

> 目标:做出"官方大店、专业时尚"的感觉,同时兼顾"可爱"(家有两女儿)。

---

## 一、风格定位

**关键词**:精致宠物生活馆 · 天青蓝调 · 清透治愈 · 高颜值可爱

**参考感觉**:高端宠物电商(如小红书爆款宠物店、精致生活方式品牌)的商品页 + 结算页。

---

## 二、色彩系统(最终定稿 · 天青蓝)

| 用途 | 颜色 | 色值 |
|---|---|---|
| 主背景 | 极浅蓝白 | #F3F9FD |
| 卡片底 | 纯白 | #FFFFFF |
| 主色/品牌色 | 天青蓝(清透治愈) | #378ADD |
| 浅主色 | 天青蓝浅 | #85B7EB |
| 点缀色 | 暖黄(亲和感) | #FAC775 |
| 文字主色 | 深蓝灰 | #0C447C |
| 文字次要 | 中性灰蓝 | #5F7590 |
| 强调/价格 | 暖橙 | #E8875A |
| 按钮/选中态 | 天青蓝 | #378ADD |

> 说明:天青蓝 + 暖黄,清透明亮,干净利落,既有专业信赖感,又不失亲和可爱。

---

## 三、排版结构(报价单页面层级)

```
┌─────────────────────────────────┐
│  顶部品牌区:店名/Logo + 副标题    │  ← 建立"官方大店"感
│  (如:羽栖 · 精致鹦鹉生活馆)      │
├─────────────────────────────────┤
│  套餐选择卡(两个主套餐并排)      │  ← 核心决策区
│  [幼鸟启航]  [成鸟无忧]          │
├─────────────────────────────────┤
│  产品明细区(可点选)              │
│  A 主体(色系选择)               │
│  B 笼具(鸟笼/架/站架)           │
│  C 配件(好打理)                 │
│  D 用品(按阶段)                 │
├─────────────────────────────────┤
│  可选加购区                      │
├─────────────────────────────────┤
│  总价结算条(实时计算)            │  ← 点选自动算总价
│  [导出图片] [复制清单]           │
├─────────────────────────────────┤
│  底部说明:合规提示 + 服务承诺    │
└─────────────────────────────────┘
```

---

## 四、交互设计(可交互报价器)

- **套餐切换**:点选「幼鸟启航 / 成鸟无忧」,自动切换清单内容
- **色系选择**:绿 / 黄化 / 蓝化,单选,联动价格
- **配件点选**:每个配件有复选框,勾选即加价
- **站架二选一**:独立站架 vs 笼内栖架(单选)
- **鸟笼架**:拓展项,可选可不选
- **实时总价**:顶部/底部结算条,随点选实时刷新
- **导出**:一键导出图片版报价单(用于发微信)

---

## 五、专业感细节(让它像官方大店)

1. 每个产品配一行小字说明(如"抽拉托盘,易清理")
2. 合规提示明确标注("带中国野生动物管理专用标识")
3. 价格用等宽数字 + ¥ 符号,右对齐
4. 套餐卡片有"推荐"角标
5. 底部有"售后服务承诺"增强信任感
