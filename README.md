# 二南瓜精选 · 鹦鹉饲养套装报价器

一个纯前端 + 零依赖 Python 后端的**可交互报价单系统**。帮朋友配置「两只和尚鹦鹉」完整饲养套装,让他在手机上点选商品、切换套餐、上传图片、生成清单图并一键提交,商家在后台实时查看。

> 一句话定位:把一份「静态报价单」升级成「可交互、可回收、可上线」的小型商业工具。

---

## ✨ 功能特性

- **可交互选品**:选鹦鹉(多品种、各自数量)、选套餐(学吃/育雏)、选笼子颜色、勾选商品
- **套餐联动**:切换「育雏套餐」自动展开育雏配置(保温箱、奶粉、喂养工具)
- **二选一互斥**:同类商品(如站杆)只能选一个,自动排他
- **推荐高亮**:氛围灯、益生菌等默认勾选 + 「★推荐」标签
- **商品图片**:统一 512×512 正方形裁剪、自动居中、点缩略图看大图
- **示意图高清通道**:配置示意图单独走不裁剪、1600px 高清上传
- **清单导出三件套**:弹窗清单 / 复制纯文本 / Canvas 生成清单图(带日期+提交者)
- **特别需求备注**:末尾自由填写,自动带进清单、清单图、提交数据
- **清单回收**:一键提交到服务器,后台 `/admin` 页面实时查看
- **后台鉴权**:后台查看页带 `?key=` 密码保护

## 🛠 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 前端 | 原生 HTML + CSS + Vanilla JS | 零框架,数据驱动渲染 |
| 后端 | Python 标准库 `http.server` | 零第三方依赖 |
| 存储 | JSON 文件 + JSONL 追加 | `data.json`(商品) / `submissions.jsonl`(提交) |
| 图片 | Canvas 前端裁剪 + multipart 上传 | 512 正方形 / 1600 高清双通道 |
| 部署 | systemd + Let's Encrypt | 开机自启、崩溃自愈、HTTPS 绿锁 |

**核心设计**:所有商品/套餐/选配都是 `data.json` 里的一份数据,前端 `render()` 纯数据驱动渲染。改价格、加商品**不用碰代码**,改 JSON 或直接在页面「编辑模式」点选即可。

## 🚀 快速开始

### 本地运行

```bash
cd app
python3 server.py          # 默认 http://localhost:8000
```

手机同 WiFi 下访问 `http://<电脑IP>:8000` 即可点选。

### 环境变量

| 变量 | 作用 | 默认 |
|---|---|---|
| `PORT` | 监听端口 | 8000 |
| `SSL` | 设为 `1` 启用 HTTPS | 关 |
| `SSL_CERT` / `SSL_KEY` | 证书路径(启用 SSL 时必填) | 空 |
| `ADMIN_KEY` | 后台查看页密码 | `123456` |

### 后台查看提交

```
http://localhost:8000/admin?key=<ADMIN_KEY>
```

## 📝 部署上线

完整步骤见 [06-部署上线步骤.md](./06-部署上线步骤.md)。一句话版:

1. 买台低价云服务器(本项目用阿里云轻量,法兰克福免备案)
2. 上传 `app/` 目录,`pip` 无需装任何东西
3. 用 systemd 托管 `server.py`,配 HTTPS 证书
4. 域名解析指向服务器 IP

## ⚠️ 说明

- 本项目为「给朋友用一次」的轻量场景设计,后台鉴权采用 URL 参数密钥(`?key=`),够用但非生产级;长期对外建议升级为登录鉴权。
